subtitle: Eleven notebooks, from coin flips to the quantum switch

Every lab follows the same loop: predict, run, explain. You make a prediction, run the simulation, and then explain what you saw. The Plotly figures run in your browser, so you can drag the sliders and rotate the 3-D views. Each lab also has a static summary figure. `assert` cells check the key numbers, so each notebook doubles as a test.

| Lab | Topic | Levels |
|---|---|---|
| [1 · Chance](01-chance.ipynb) | Repeated trials, the law of large numbers, randomization | 1–2 |
| [2 · Bayes](02-bayes.ipynb) | Base rates, natural frequencies, updating | 1–2 |
| [3 · Causal inference](03-causal-inference.ipynb) | Confounding, do(·), back-door, front-door, colliders | 2–4 |
| [4 · Interference](04-interference.ipynb) | Mach–Zehnder, phase, which-path information | 1–5 |
| [5 · Qubits](05-qubit-bloch.ipynb) | The Bloch sphere, measurement, mixed states | 5 |
| [6 · Entanglement and Bell](06-entanglement-bell.ipynb) | CHSH, Werner states, concurrence | 5–6 |
| [7 · Noise and channels](07-noise-channels.ipynb) | Kraus operators, Choi matrices, decoherence | 5–6 |
| [8 · Variational circuits](08-variational-gradients.ipynb) | Parameter shift, training, barren plateaus | 7 |
| [9 · Quantum switch](09-quantum-switch.ipynb) | Indefinite causal order | 6 |
| [10 · Classical shadows](10-classical-shadows.ipynb) | Randomized measurement, sample complexity | 7 |
| [11 · Quantum causal inference](11-quantum-causal-inference.ipynb) | Common cause vs cause–effect, causal compatibility | 6–7 |

:::{important}
These labs are exact classical simulations of small textbook models. They do not run on quantum hardware. A working simulation is not evidence that a physical system follows the model.
:::

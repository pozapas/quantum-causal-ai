## Learn

Noise changes a quantum state through unwanted coupling or control error. Depolarization moves a state toward the maximally mixed state. Dephasing reduces coherence in a selected basis. These channels have different effects even when a single chosen measurement produces similar counts.

Quantum error correction stores logical information across several physical systems. Syndrome measurements reveal selected error properties without directly reading the logical state. A recovery operation then corrects an allowed error set. This procedure does not copy an unknown state into independent identical copies.

An encoding is useful only under its stated noise and control assumptions. A repetition code can correct certain bit flips but not arbitrary single-qubit errors. Fault tolerance also addresses faults during the correction process. Report logical error rates with the complete experimental procedure.

:::{important} Key relation
:class: qcai-equation
E\_p(rho) = (1-p)rho + p I/2, 0&lt;=p&lt;=1. For rho=(I+r·sigma)/2, depolarization sends r to (1-p)r.
:::

:::{tip} Worked example
Apply depolarization with p = 0.2 to \|0&gt;&lt;0\|. The output is 0.8 diag(1,0) + 0.2 diag(1/2,1/2), or diag(0.9,0.1). Its purity is 0.82. This p convention differs from some Pauli-error parameterizations.
:::

## Practice

:::{admonition} Exercise
:class: tip

Apply the same depolarization convention with p = 0.4 to \|1&gt;&lt;1\|. Give the output probabilities and purity.
:::

:::{dropdown} Solution

The output diagonal is (0.2,0.8). Its purity is 0.2 squared plus 0.8 squared, which is 0.68. Increasing depolarization reduces this initially pure state purity.
:::

## Check your understanding

**What does a syndrome measurement seek to reveal?**

- **A.** The full unknown logical state
- **B.** Information about an error without directly reading logical data
- **C.** Independent copies of the logical state

:::{dropdown} Show the answer
**B. Information about an error without directly reading logical data**

A syndrome is designed to diagnose a correctable error class while preserving logical information. Reading the logical state itself would defeat that goal.
:::

:::{caution} Scope and assumptions
Noise parameters depend on convention. This lesson uses mixing with I/2, not the alternative total Pauli-error probability.
:::

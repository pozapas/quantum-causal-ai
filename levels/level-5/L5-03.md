## Learn

Two paths can contribute amplitudes to the same outcome. Add those amplitudes before taking the squared magnitude. Their relative phase controls whether they reinforce or cancel. Adding the two path probabilities instead would remove the interference term.

A phase applied to the whole state has no effect on outcome probabilities. A phase applied to only one component can change a later measurement. This distinction separates global phase from relative phase. The measurement apparatus selects which distinction is observable.

Interference is not a claim that a detector reports every path. One trial still gives one registered outcome. The circuit combines amplitudes before detection. Compare several phase settings with repeated preparation to test the resulting probability curve.

:::{important} Key relation
:class: qcai-equation
\|psi(phi)&gt; = (\|0&gt; + exp(i phi)\|1&gt;)/sqrt(2); after H, P(0) = (1 + cos(phi))/2. Here phi is relative phase in radians.
:::

:::{tip} Worked example
An equal path state receives relative phase pi/3. After a Hadamard gate, P(0) = (1 + 1/2)/2 = 3/4. The complementary probability is 1/4. Without the final combining gate, both path-basis probabilities would remain 1/2.
:::

## Practice

:::{admonition} Exercise
:class: tip

Set the relative phase to 2pi/3. Find the two probabilities after the combining Hadamard gate.
:::

:::{dropdown} Solution

The cosine of 2pi/3 is -1/2. Thus P(0) is 1/4 and P(1) is 3/4. Their sum remains one. Relative phase changes the interference result.
:::

## Check your understanding

**Which operation can reveal a relative phase?**

- **A.** A measurement in a suitable changed basis
- **B.** Reading a global phase directly
- **C.** Adding path probabilities before combining

:::{dropdown} Show the answer
**A. A measurement in a suitable changed basis**

A changed basis can turn a relative phase into unequal outcome probabilities. Global phase remains absent from every measurement probability.
:::

:::{caution} Scope and assumptions
This formula assumes equal path amplitudes, an ideal phase operation, and a coherent final combination.
:::

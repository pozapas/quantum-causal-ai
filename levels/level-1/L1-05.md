## Learn

Random assignment uses a chance process to choose a treatment for each participant. For example, a fair coin can select between two study methods. The assignment must happen before the result is measured, using the planned rule.

Random assignment can prevent the experimenter from deliberately placing stronger learners in one group. It balances other causes on average across repeated assignments. One small experiment can still have groups that differ by chance, so record group sizes and uncertainty.

A fair experiment also needs a clear outcome and similar measurement. If one group receives extra practice and a different test, two changes occur together. Random assignment alone cannot repair a badly defined comparison or a missing result.

:::{important} Key relation
:class: qcai-equation
Planned comparison: average result under method A minus average result under method B.
:::

:::{tip} Worked example
Twelve learners receive method A or B by a planned random rule. Both groups study for twenty minutes and take the same test. This setup is clearer than letting the teacher give A only to learners who already score well.
:::

## Practice

:::{admonition} Exercise
:class: tip

Two garden plots receive different plant foods. Suggest a random assignment rule and one outcome measured in the same way for every plant.
:::

:::{dropdown} Solution

Randomly assign similar plants to the two foods before growth is measured. Record height change over the same time interval with the same measuring method. Use enough plants to study variation.
:::

## Check your understanding

**What does random assignment guarantee in one small experiment?**

- **A.** Use of the stated chance rule, not identical groups
- **B.** Exactly equal starting ability
- **C.** A large treatment effect

:::{dropdown} Show the answer
**A. Use of the stated chance rule, not identical groups**

A correctly applied chance rule defines random assignment. It does not guarantee identical groups or any particular treatment effect in one small experiment.

## Learn

A model is a limited description used to answer a question. A fair-coin model assigns equal probabilities to two outcomes. It leaves out many physical details. Those omissions can be useful if the model still predicts the results needed for the task.

Write the assumptions before you use the model. For repeated coin trials, you might assume unchanged conditions and independent tosses. A useful test compares predictions with new results. It also states how much random variation is compatible with the planned check.

A failed check is information. It can reveal a recording error, a broken assumption, or an unsuitable model. Do not change the rule only to hide a failure. Record the original prediction, inspect the setup, and explain any revised model.

:::{important} Key relation
:class: qcai-equation
Model record: question + assumptions + prediction + check + limits.
:::

:::{tip} Worked example
A learner models a spinner as four equally likely colours and predicts roughly one quarter red over many trials. The spinner repeatedly sticks near red. This suggests that equal chances may be a poor assumption. The learner records the issue instead of discarding red results.
:::

## Practice

:::{admonition} Exercise
:class: tip

Write a model record for drawing a blue counter from a bag with two blue and six white counters, with replacement and mixing.
:::

:::{dropdown} Solution

The model assumes equal selection chances, replacement, mixing, and unchanged contents. It predicts P(blue)=2/8=1/4. Record repeated outcomes and use a planned variation-aware check rather than demanding exactly one quarter every time.
:::

## Check your understanding

**What should happen when a planned check fails?**

- **A.** Delete results that disagree
- **B.** Claim success without a record
- **C.** Record the failure and examine assumptions

:::{dropdown} Show the answer
**C. Record the failure and examine assumptions**

A recorded failure supports diagnosis and honest revision. Deleting inconvenient results changes the evidence and prevents a valid assessment of the original prediction.
:::

:::{caution} Scope and assumptions
A model can pass a limited test and still fail outside the tested conditions.
:::

## Learn

Probability is a number that describes uncertainty in a model. Zero means impossible and one means certain. A value between them describes an uncertain event. The model must state the possible outcomes and how the trial works.

If each counter has an equal chance of selection, count the counters that satisfy the event. Divide by the total number of counters. Equal chance is an assumption about the draw method, not a result of using fractions.

The complement of an event means that the event does not occur. For a red draw, the complement is a non-red draw. Their probabilities add to one when every draw gives exactly one of these two results.

:::{important} Key relation
:class: qcai-equation
P(red) = number of red counters / total counters. P(not red) = 1 - P(red).
:::

:::{tip} Worked example
A mixed bag contains three red counters and seven white counters of the same size. Under equal selection chances, P(red)=3/10=0.3. The non-red probability is 7/10=0.7. These values add to one, as required for the two exhaustive events.
:::

## Practice

:::{admonition} Exercise
:class: tip

A bag contains four green counters and one orange counter. Find P(green) and P(not green) for an equal-chance draw.
:::

:::{dropdown} Solution

There are five counters. P(green)=4/5=0.8 and P(not green)=1/5=0.2. The values add to one because green and not green cover every possible draw.
:::

## Check your understanding

**When can favourable-count divided by total-count be used directly?**

- **A.** When individual outcomes are equally likely
- **B.** Whenever outcome names differ
- **C.** Only when a result is certain

:::{dropdown} Show the answer
**A. When individual outcomes are equally likely**

The counting rule requires equal probabilities for the counted individual outcomes. Unequal chances require a model that assigns their different weights.
:::

:::{caution} Scope and assumptions
Equal-sized counters still require a draw method that does not favour a colour.
:::

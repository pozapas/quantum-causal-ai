## Learn

A directed graph contains nodes and arrows. A node represents a variable. An arrow X to Y proposes a direct causal influence relative to the variables included in the model. A directed acyclic graph has no path of arrows that returns to its starting node.

Three small patterns matter. In a chain X to M to Y, influence can pass through M. In a common-cause pattern X from Z to Y, Z affects both endpoints. In a collider X to C from Y, both endpoints affect C.

Conditioning has different effects on these patterns. In suitable simple models, conditioning on a common cause can remove an association. Conditioning on a collider can create one. Graphs make these distinctions explicit, but their arrows and missing arrows require substantive assumptions.

:::{important} Key relation
:class: qcai-equation
Chain: X -&gt; M -&gt; Y. Common cause: X &lt;- Z -&gt; Y. Collider: X -&gt; C &lt;- Y.
:::

:::{tip} Worked example
Suppose battery failure and bulb failure can each make a lamp stay dark. The model has battery failure pointing to darkness and bulb failure pointing to darkness. Darkness is a collider. Studying only dark lamps can associate two otherwise independent failure causes.
:::

## Practice

:::{admonition} Exercise
:class: tip

Classify these proposed patterns: rain -&gt; wet road -&gt; slipping; age -&gt; shoe size and age -&gt; reading skill; skill -&gt; selection &lt;- luck.
:::

:::{dropdown} Solution

The first is a chain through wet road. The second is a common-cause pattern through age. The third is a collider at selection. Classification describes the proposed arrows, not proof that they are correct.
:::

## Check your understanding

**Which node is the collider in X -&gt; C &lt;- Y?**

- **A.** X
- **B.** C
- **C.** Y

:::{dropdown} Show the answer
**B. C**

Both arrows enter C, so C is the collider on this path. Conditioning on it can create association under suitable model assumptions.
:::

:::{caution} Scope and assumptions
A graph is a causal assumption, not a decoration inferred from correlation alone.
:::

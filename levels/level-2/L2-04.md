## Learn

For events A and B, conditional probability P(A given B) restricts attention to cases where B occurs. Divide the probability of both events by the probability of B. This formula requires P(B) to be greater than zero.

Events are independent when learning that one occurred does not change the probability of the other. For a positive-probability B, this gives P(A given B)=P(A). Independence is a property of the specified probability distribution and is not the same as no causal relation.

A two-way table helps keep the counts visible. Label rows and columns, include their totals, and check that every case appears once. Reversing the condition changes the denominator, which can change the answer even when the intersection count stays the same.

:::{important} Key relation
:class: qcai-equation
P(A \| B)=P(A and B)/P(B), for P(B)&gt;0. The vertical bar means given.
:::

:::{tip} Worked example
In forty records, twelve have both A and B, twenty have B, and twenty-four have A. Thus P(A given B)=12/20=0.6 and P(A)=24/40=0.6. For these binary events in this table, the equality is consistent with independence.
:::

## Practice

:::{admonition} Exercise
:class: tip

In fifty records, fifteen have both A and B, twenty-five have B, and twenty have A. Find P(A given B) and P(A). Are the events independent in this table?
:::

:::{dropdown} Solution

P(A given B)=15/25=0.6, while P(A)=20/50=0.4. They differ, so A and B are not independent in this empirical table. This conclusion does not itself identify a cause.
:::

## Check your understanding

**When is P(A given B) undefined by the elementary ratio formula?**

- **A.** When A is possible
- **B.** When P(B)=0
- **C.** When the events are independent

:::{dropdown} Show the answer
**B. When P(B)=0**

The elementary formula divides by P(B). A zero denominator is undefined, so the positive-probability condition is necessary for this formula.
:::

:::{caution} Scope and assumptions
An empirical table estimates a population relationship. Sampling uncertainty remains outside this exact table calculation.
:::

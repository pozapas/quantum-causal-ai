## Learn

A function assigns one output to each allowed input. We write f(x) for the output associated with input x. The domain is the set of allowed inputs. The domain can be restricted by mathematics or by the intended application.

A prediction function takes recorded features and produces an estimate. Its output can differ from the measured result. Write the prediction and observation separately so that you can calculate an error instead of silently treating the model as the real system.

Some outcomes vary even when the recorded input is unchanged. A deterministic prediction can summarize a typical value while missing that variation. A probability model can represent multiple possible results. Later lessons combine functions with unobserved inputs to model such variation.

:::{important} Key relation
:class: qcai-equation
f(x)=2x+1. Prediction error here means observed value minus predicted value.
:::

:::{tip} Worked example
A model predicts f(3)=2 times 3 plus 1, which is 7. The observed result is 9, so the signed error is 9-7=2. The calculation checks this prediction only; it does not prove that the whole function is suitable.
:::

## Practice

:::{admonition} Exercise
:class: tip

Let g(x)=4x-2. Find g(5). If the observed result is 16, compute observed minus predicted.
:::

:::{dropdown} Solution

The predicted value is g(5)=20-2=18. The signed error is 16-18=-2. A negative error means the prediction is larger than the observation under this error convention.
:::

## Check your understanding

**What must a function assign to each input in its domain?**

- **A.** Every possible output at once
- **B.** No defined output
- **C.** Exactly one output

:::{dropdown} Show the answer
**C. Exactly one output**

A function has one output for each allowed input. A stochastic model can instead describe a distribution, or include additional random inputs.
:::

:::{caution} Scope and assumptions
One small prediction error does not establish generalization or a causal mechanism.
:::

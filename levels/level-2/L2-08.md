## Learn

Observation asks about records in which a variable takes a value through its ordinary causes. An intervention sets a variable according to a specified action. These can produce different populations because the usual reasons for that variable's value no longer apply in the same way.

The notation do(X=x) describes an ideal intervention that replaces the mechanism generating X with a fixed value x. In the graph, remove arrows entering X. Keep the other mechanisms unchanged. This is a precise model operation, not a guarantee about every practical action.

If a shared cause affects X and Y, observing X can give information about that cause. Setting X need not give the same information. This difference explains why an observational conditional probability is not generally the probability of Y after an intervention.

:::{important} Key relation
:class: qcai-equation
P(Y \| X=x) is observational. P(Y \| do(X=x)) is interventional. They need not be equal.
:::

:::{tip} Worked example
Let a hidden binary Z be equally likely zero or one. Set X=Z and Y=Z in the observational model. Observing X=1 implies Y=1. Under do(X=1), the rule for X is replaced but Z remains balanced, so P(Y=1)=1/2.
:::

## Practice

:::{admonition} Exercise
:class: tip

In the same model, compare P(Y=1 given X=0) with P(Y=1 given do(X=0)). Explain the difference.
:::

:::{dropdown} Solution

Observing X=0 implies Z=0, so Y=1 has probability zero. Setting X=0 leaves Z unchanged, so Y=1 has probability one half. The intervention breaks the Z-to-X mechanism only.
:::

## Check your understanding

**Which arrows are removed by the ideal operation do(X=x)?**

- **A.** All arrows leaving Y
- **B.** Every arrow in the graph
- **C.** Arrows entering X

:::{dropdown} Show the answer
**C. Arrows entering X**

The intervention replaces X's ordinary generating mechanism. Its incoming arrows are removed while other mechanisms and outgoing causal influences remain as specified.
:::

:::{caution} Scope and assumptions
Real actions can have side effects. The ideal intervention model must be matched to the actual action.
:::

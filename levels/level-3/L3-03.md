## Learn

A matrix is a rectangular array of numbers. A matrix can transform a vector. For each output entry, multiply one matrix row by the input column, then add the products. The number of matrix columns must equal the number of input entries.

A square complex matrix U is unitary when its conjugate transpose times itself equals the identity matrix. The conjugate transpose changes rows into columns and conjugates every entry. A unitary matrix preserves inner products and norms. Its inverse is its conjugate transpose.

Closed quantum systems use unitary time evolution. Measurements and noise need more general descriptions. A matrix with real positive entries is not necessarily a quantum gate. Also, a stochastic transition matrix preserves total probability under its chosen convention, which differs from preserving an amplitude vector's norm.

:::{important} Key relation
:class: qcai-equation
w = Uv; U†U = I for a unitary U. Here † means conjugate transpose and I leaves every vector unchanged.
:::

:::{tip} Worked example
Use the swap matrix X with rows (0,1) and (1,0). Apply it to v = (3/5,4/5). The result is (4/5,3/5). The squared norm remains 16/25 + 9/25 = 1. Applying X again returns the original vector.
:::

## Practice

:::{admonition} Exercise
:class: tip

Apply H = (1/√2)\[\[1,1\],\[1,-1\]\] to v = (1,0). Then apply H once more.
:::

:::{dropdown} Solution

The first result is (1/√2,1/√2). The second result is (1,0), because the second output entry cancels. Both output vectors have norm one.
:::

## Check your understanding

**Which property must a unitary matrix preserve?**

- **A.** Every individual vector entry
- **B.** The norm of every input vector
- **C.** The sign of every real entry

:::{dropdown} Show the answer
**B. The norm of every input vector**

The identity U†U = I makes the squared output norm equal the squared input norm for every vector.
:::

:::{caution} Scope and assumptions
Unitary evolution alone cannot describe every physical operation on a subsystem. Noise can reduce subsystem purity.
:::

## Learn

Optimization chooses parameters to reduce a stated loss function. A loss measures error under a chosen rule. In gradient descent, subtract a learning rate times the gradient from the current parameters. A small step follows a local direction of decreasing loss when regularity conditions hold.

The learning rate controls the step size. A large value can overshoot a minimum or make the procedure diverge. A very small value can require many steps. Some loss functions contain several local minima or nearly flat regions, so a small gradient need not certify a useful solution.

Learning requires more than minimizing training loss. Evaluate predictions on data that the fitting procedure did not use. For causal learning, also test whether the target intervention is identifiable. For quantum learning, include data encoding, measurement, and classical computation costs when comparing methods.

:::{important} Key relation
:class: qcai-equation
θnew = θold - η∇L(θold). Here θ is a parameter vector, L is the loss, and η is a positive learning rate.
:::

:::{tip} Worked example
Use L(θ) = (θ-2)². Its derivative is 2(θ-2). Start at θ = 0 with learning rate 0.25. The derivative is -4, so the new parameter is 1. The loss falls from 4 to 1 after this step.
:::

## Practice

:::{admonition} Exercise
:class: tip

For L(θ) = (θ-3)², start at θ = 1 and use learning rate 0.1. Find the new parameter and loss.
:::

:::{dropdown} Solution

The derivative at one is 2(1-3) = -4. The new parameter is 1.4. The new loss is (1.4-3)² = 2.56, below the initial loss of four.
:::

## Check your understanding

**What does a smaller training loss establish by itself?**

- **A.** A correct causal model
- **B.** Better fit under that training objective
- **C.** A quantum computational advantage

:::{dropdown} Show the answer
**B. Better fit under that training objective**

Training loss measures the chosen fit criterion. It does not establish causal validity, performance on new data, or computational advantage.
:::

:::{caution} Scope and assumptions
A local decrease is not a certificate of a global optimum or a valid causal interpretation.
:::

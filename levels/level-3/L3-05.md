## Learn

An eigenvector keeps its direction under a matrix transformation. The matrix can multiply the vector by a number called its eigenvalue. The vector must be nonzero. Solving an eigenvalue problem reveals directions that the transformation treats in a particularly simple way.

A Hermitian matrix equals its conjugate transpose. Its eigenvalues are real, and an orthonormal eigenbasis can be chosen in finite dimensions. Quantum observables use Hermitian operators. Their eigenvalues name possible outcomes in an ideal projective measurement, while the state determines the probabilities.

An expectation value is a weighted average of measurement outcomes. It need not be one of the possible outcomes. Measure many independently prepared copies to estimate it. A single measurement generally does not reveal the full state or its expectation value exactly.

:::{important} Key relation
:class: qcai-equation
Av = λv with v ≠ 0. For a normalized state ψ and Hermitian A, the expectation is ⟨A⟩ = ψ†Aψ. The number λ is an eigenvalue.
:::

:::{tip} Worked example
The matrix Z has diagonal entries 1 and -1, with zero entries elsewhere. The vector (1,0) has eigenvalue 1. The vector (0,1) has eigenvalue -1. In the state (1/√2,1/√2), these outcomes have equal probabilities, so the expectation is zero.
:::

## Practice

:::{admonition} Exercise
:class: tip

For the same Z measurement, outcome 1 has probability 0.8 and outcome -1 has probability 0.2. Calculate the expectation.
:::

:::{dropdown} Solution

Multiply each outcome by its probability and add. The expectation is 1(0.8) + (-1)(0.2) = 0.6. A single ideal measurement still returns either 1 or -1.
:::

## Check your understanding

**Can the expectation of a two-outcome Z measurement equal 0.6?**

- **A.** Yes, as a weighted average
- **B.** No, because only eigenvalues can be averages
- **C.** Only if every result is 0.6

:::{dropdown} Show the answer
**A. Yes, as a weighted average**

An average can lie between the possible outcomes. Individual ideal Z outcomes remain 1 and -1 in this convention.
:::

## Learn

A feature map embeds an input x into a quantum state \|phi(x)&gt;. An overlap can define a positive semidefinite kernel. A classical learner can then use the kernel matrix. The quantum circuit supplies a similarity estimate rather than a causal interpretation of the data.

The total procedure includes data encoding, circuit execution, repeated measurements, kernel storage, optimization, and prediction. A short overlap circuit does not make arbitrary classical data loading free. The full cost depends on the input representation and the accuracy required for every estimated matrix entry.

A meaningful advantage claim compares strong classical methods with comparable data and resources. Hardness of a feature-map calculation alone does not establish learning advantage. Training examples can make prediction easier for classical methods. Report generalization and resource scaling separately.

:::{important} Key relation
:class: qcai-equation
k(x,z) = \|&lt;phi(x)\|phi(z)&gt;\|². For \|phi(x)&gt; = Ry(x)\|0&gt;, k(x,z) = cos²((x-z)/2). x and z are real rotation angles.
:::

:::{tip} Worked example
For x=0 and z=pi/2, the simple rotation kernel is one half. This kernel is easy to compute classically. Implementing it on a quantum device gives no computational advantage by itself. It remains a useful small example for testing the overlap-estimation workflow.
:::

## Practice

:::{admonition} Exercise
:class: tip

Use x=pi/3 and z=pi. Compute the kernel. Name two costs that must accompany a claimed quantum speedup.
:::

:::{dropdown} Solution

The angle difference is -2pi/3, so the half-angle cosine squared is 1/4. Include data encoding and measurement repetitions. Also report classical training and kernel storage costs when they contribute.
:::

## Check your understanding

**Does a hard feature calculation alone prove a learning advantage?**

- **A.** Yes, for any data set
- **B.** Only when a kernel is normalized
- **C.** No, the learning task and classical data access also matter

:::{dropdown} Show the answer
**C. No, the learning task and classical data access also matter**

The comparison concerns a complete learning task. Training data, approximation, and classical alternatives can change its difficulty relative to computing one feature exactly.
:::

:::{caution} Scope and assumptions
The rotation kernel here is deliberately classically tractable. It illustrates mechanics and cannot support a quantum advantage claim.
:::

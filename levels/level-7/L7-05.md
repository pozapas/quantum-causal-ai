## Learn

A flexible learner can match observed probabilities while representing the wrong intervention behavior. This is a fundamental identification problem rather than an optimizer defect. Define the observational or operational equivalence class before choosing a model architecture. The target must be constant across that class to be identifiable.

For quantum processes, restricted instruments can make distinct channels or graphs indistinguishable. Hidden environments can enlarge the equivalence class. An expressive quantum or classical learner cannot create information absent from the data. A prior can choose an answer but must be disclosed as an additional assumption.

Use a constructive test. Find two allowed models with identical accessible predictions but different target values. Such a pair disproves identification for that design. To repair the study, add an informative intervention, narrow the justified model class, or report bounds instead of a point claim.

:::{important} Key relation
:class: qcai-equation
A target T is identifiable under data map D when D(M1)=D(M2) implies T(M1)=T(M2) for every allowed pair of models M1,M2.
:::

:::{tip} Worked example
Observe only Z outcomes after a \|0&gt; input. Identity and complete Z dephasing both predict outcome 0. Their X-coherence transmission differs on \|+&gt; input. Thus coherence transmission is not identifiable from the original data. No training loss can resolve this exact equality.
:::

## Practice

:::{admonition} Exercise
:class: tip

A learner chooses identity from those original records by imposing a minimum-noise prior. Is the coherence conclusion data-identified? Specify an experiment that could test it.
:::

:::{dropdown} Solution

It is prior-selected rather than identified by those records. Prepare \|+&gt; and measure X after the device. Identity predicts + with probability one, while complete Z dephasing predicts one half.
:::

## Check your understanding

**What disproves target identification?**

- **A.** A low training loss
- **B.** Two data-equivalent models with different target values
- **C.** A larger neural model

:::{dropdown} Show the answer
**B. Two data-equivalent models with different target values**

If two permitted models give identical available data but different targets, that data cannot select one target value without an additional assumption.
:::

:::{caution} Scope and assumptions
The model class and operation set are part of every identification statement. Changing either can change the result.
:::

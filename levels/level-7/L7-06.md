## Learn

Sample complexity counts the observations needed for a stated accuracy and failure probability. Query complexity counts accesses to an oracle or process. Gate complexity counts circuit operations. Wall-clock cost also includes state preparation, reset, compilation, communication, and analysis. These quantities cannot be substituted without an access model.

For a bounded measurement mean, independent samples give a simple concentration bound. The bound can be conservative but it states a reproducible requirement. Correlated drift or adaptive stopping can invalidate an independence-based analysis. Declare those conditions before interpreting the calculated count.

A quantum advantage can concern one resource while increasing another. State whether the comparison counts classical samples, coherent queries, quantum memory, or compute time. A theoretical oracle model can be useful, but its assumptions must be visible beside any practical claim.

:::{important} Key relation
:class: qcai-equation
For independent outcomes in \[-1,1\], P(\|mean-mu\|&gt;=epsilon) &lt;= 2 exp(-N epsilon²/2). Thus N &gt;= (2/epsilon²) ln(2/delta) suffices for failure probability at most delta.
:::

:::{tip} Worked example
Choose epsilon=0.1 and delta=0.05. The bound gives N &gt;= 200 ln(40), approximately 737.8. Round upward to 738 independent shots. This bound concerns one observable mean. Estimating many means or searching models needs additional error control.
:::

## Practice

:::{admonition} Exercise
:class: tip

Use epsilon=0.2 and delta=0.1. Find the sufficient integer count. Explain what the count does not measure.
:::

:::{dropdown} Solution

The bound gives N &gt;= 50 ln(20), approximately 149.79. Use 150 independent shots. This does not count gate operations, state-preparation time, or the extra cost of estimating several observables.
:::

## Check your understanding

**Which statement is correct about resource counts?**

- **A.** Queries, copies, and wall-clock time are interchangeable
- **B.** A small shot count guarantees low total cost
- **C.** Each count needs its own stated access and cost model

:::{dropdown} Show the answer
**C. Each count needs its own stated access and cost model**

Different resource measures describe different operations. An algorithm can save queries while spending more preparation or computation time, so the comparison must state its model.
:::

:::{caution} Scope and assumptions
The concentration bound assumes independent bounded outcomes and a fixed analysis. Time-correlated noise requires another justification.
:::

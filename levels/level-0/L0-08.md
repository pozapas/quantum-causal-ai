## Learn

A bit is a unit of information with two possible values. We write the values as zero and one. A bit can record which of two labels applies. The labels need a stated meaning to be useful.

For a lamp record, you can let zero mean off and one mean on. This record is about the lamp. It is not the lamp itself. If someone reverses the meanings, the same written number describes a different state.

A quantum bit is called a qubit. Its rules are richer than these two labels, and later lessons explain them. Measuring a qubit in a chosen two-outcome measurement can produce a recorded bit. A qubit is not a tiny lamp.

:::{important} Key relation
:class: qcai-equation
Record rule: 0 means off; 1 means on.
:::

:::{tip} Worked example
Three lamps are on, off, and on. With the stated rule, write 1, 0, 1. A reader who knows the rule can recover the recorded states. Without the rule, the numbers do not identify the lamp meanings.
:::

## Practice

:::{admonition} Exercise
:class: tip

Let zero mean closed and one mean open. Record three doors that are closed, closed, and open.
:::

:::{dropdown} Solution

The record is 0, 0, 1. The first two zeros mean closed, and the final one means open. State the code with the record so another reader can use it.
:::

## Check your understanding

**What values can one classical bit have?**

- **A.** Only ten
- **B.** Zero or one
- **C.** Any whole sentence at once

:::{dropdown} Show the answer
**B. Zero or one**

A classical bit has two possible values, written zero and one. Longer messages require more bits and an agreed way to interpret them.
:::

:::{caution} Scope and assumptions
A qubit requires quantum state rules. The lamp code is a classical information example.

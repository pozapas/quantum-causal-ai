## Learn

A count tells you how many objects are in a group. Touch each object once as you say its number. Keep the objects still. This helps you avoid counting one object twice.

A record keeps your count after the objects move. You can draw one mark for each object. Write a name above each group. Another person can then see which count belongs to which group.

Science starts with careful records. A larger count does not explain why there are more objects. First describe what you saw. Later, you can ask what could have made the groups different.

:::{important} Key relation
:class: qcai-equation
3 + 2 = 5. Three objects and two more objects make five objects.
:::

:::{tip} Worked example
Put three red blocks and two blue blocks on a table. Count the red blocks: one, two, three. Count the blue blocks: one, two. There are five blocks in all. The red group has one more block.
:::

## Practice

:::{admonition} Exercise
:class: tip

Draw four circles and three squares. How many shapes are there? Which group has more shapes?
:::

:::{dropdown} Solution

There are seven shapes because four plus three equals seven. The circle group has one more shape than the square group. Count each drawing once to check.
:::

## Check your understanding

**Which record helps another person check a count?**

- **A.** A named group with one mark per object
- **B.** A guess with no objects
- **C.** A colour with no number

:::{dropdown} Show the answer
**A. A named group with one mark per object**

The named marks connect the written count to the objects. Another person can count the marks and compare the result.
:::

:::{caution} Scope and assumptions
A count describes this group. It does not by itself explain a cause.
:::

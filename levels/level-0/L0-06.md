## Learn

A pattern is a rule you notice in examples. The colours red, blue, red, blue suggest an alternating rule. A prediction uses that rule to say what might come next before you look at it.

A prediction can be wrong. The maker of the pattern might change the rule, or you might have guessed the wrong rule. Record the prediction first. Then compare it with a new result that you did not use.

Artificial intelligence often learns patterns from examples. A correct answer on familiar examples is not enough. New examples help test whether a system learned a useful rule or only remembered the examples it already saw.

:::{important} Key relation
:class: qcai-equation
Rule: add 2. Sequence: 2, 4, 6, 8.
:::

:::{tip} Worked example
You see the numbers 3, 6, and 9. You propose the rule add three and predict 12. The next hidden number is 12, so this test agrees with your rule. Other rules may still fit the first numbers.
:::

## Practice

:::{admonition} Exercise
:class: tip

Use the rule add four. Start at 1. Write the next three numbers, then describe how you would check your prediction.
:::

:::{dropdown} Solution

The next numbers are 5, 9, and 13. Add four at each step. Compare these predictions with new results made with the stated rule.
:::

## Check your understanding

**Which result gives a useful new test of a learned rule?**

- **A.** The same example copied again
- **B.** A score with no answer
- **C.** An example kept out of learning

:::{dropdown} Show the answer
**C. An example kept out of learning**

An example kept out of learning can test a new prediction. Repeating a remembered answer does not provide the same evidence.
:::

:::{caution} Scope and assumptions
Several rules can fit a short pattern. Agreement with one new case is not a proof.
:::

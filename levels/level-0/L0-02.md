## Learn

A group can contain objects that follow a rule. You can put all red objects together. You can also group objects by shape. State the rule before you start to sort the objects.

One object can follow two rules. A red square is red and square. If you change the rule, its group can change. The object did not change. Your question about the object changed.

An artificial intelligence system can also sort examples into groups. It needs a clear task and useful examples. A wrong group name can lead to a wrong result, even when a computer works quickly.

:::{important} Key relation
:class: qcai-equation
A category is a named group. Here the rule is: colour is red.
:::

:::{tip} Worked example
Take a red square, a blue square, and a red circle. With the colour rule, two objects are red. With the shape rule, two objects are squares. Each result is correct for its own stated rule.
:::

## Practice

:::{admonition} Exercise
:class: tip

You have a green triangle, a green circle, and a yellow circle. Sort by colour. Then sort by shape.
:::

:::{dropdown} Solution

The colour groups contain two green objects and one yellow object. The shape groups contain one triangle and two circles. Each object belongs to one group for each rule.
:::

## Check your understanding

**Why can a red square appear in two different sorts?**

- **A.** It becomes a new object
- **B.** The sorting rule changes
- **C.** Counting always fails

:::{dropdown} Show the answer
**B. The sorting rule changes**

A colour rule and a shape rule ask different questions. The same object has both properties and can satisfy both rules.
:::

:::{caution} Scope and assumptions
Real categories can overlap. A simple sorting task does not represent every learning problem.
:::

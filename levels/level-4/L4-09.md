## Learn

A counterfactual asks what would have happened to the same unit under a different action. It links an observed situation to an alternative situation through shared background factors. An interventional population average alone does not usually specify this cross-situation link for one observed individual.

Structural models answer counterfactual questions in three steps. Abduction updates beliefs about background variables using the observed evidence. Action replaces the mechanism specified by the alternative intervention. Prediction computes the outcome under the modified model using the updated background beliefs from the original situation.

The answer can depend on untestable details of the structural functions. Two models can agree on observed data and even on some intervention distributions, yet disagree on individual counterfactuals. Report the model and evidence explicitly. A fitted predictor with one input edited is not automatically a counterfactual model.

:::{important} Key relation
:class: qcai-equation
For Y=2X+U, evidence X=1,Y=5 implies U=3. Under the alternative do(X=0), the same-unit counterfactual is Y0=2(0)+3=3.
:::

:::{tip} Worked example
Use the deterministic model Y=2X+U and observe X=1,Y=5. First infer U=3 from the observed equation. Next replace the X mechanism with X=0. Finally apply the unchanged Y equation with U=3. The counterfactual Y is three for this modeled unit.
:::

## Practice

:::{admonition} Exercise
:class: tip

Use Y=3X+U. Observe X=2,Y=10. Under this exact structural model, what would Y have been if X had been zero?
:::

:::{dropdown} Solution

Abduction gives U=10-3(2)=4. The alternative action sets X to zero. Prediction with the same U gives Y=3(0)+4=4 for this modeled unit.
:::

## Check your understanding

**Which step uses the factual evidence to update background variables?**

- **A.** Action
- **B.** Abduction
- **C.** Prediction

:::{dropdown} Show the answer
**B. Abduction**

Abduction infers background information from factual evidence. Action changes the mechanism, and prediction evaluates the changed model with that information.
:::

:::{caution} Scope and assumptions
This calculation assumes an exact structural equation and shared background variable. Observational regression alone does not establish those assumptions.
:::

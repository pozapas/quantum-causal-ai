## Learn

A confounder can create an open backdoor path from treatment to outcome. A mediator lies on a directed path from treatment to outcome. A collider has two arrows pointing into it along a particular path. These are graph roles relative to a question, rather than permanent labels for every use.

Conditioning on a suitable confounder can block a noncausal path. Conditioning on a mediator can remove part of the total effect that you intend to measure. Conditioning on a collider can open a path that was previously blocked. More adjustment is therefore not always better adjustment.

Selection is a common source of collider bias. Suppose two independent factors can each cause inclusion in a dataset. Among included cases, learning that one factor is absent can make the other more likely. This association comes from the inclusion rule and does not establish a causal link between the factors.

:::{important} Key relation
:class: qcai-equation
A→C←B is a collider path. With independent fair binary A and B and C = max(A,B), P(A=1\|C=1)=2/3, while P(A=1,B=1\|C=1)=1/3.
:::

:::{tip} Worked example
Let A and B be independent fair binary variables. Include a record when at least one is one. The retained pairs are 01, 10, and 11, each equally likely. Within these records, A and B are dependent: the joint probability of both being one is 1/3, not (2/3)².
:::

## Practice

:::{admonition} Exercise
:class: tip

Under the same inclusion rule, calculate P(B=1\|A=0,C=1) and P(B=1\|A=1,C=1).
:::

:::{dropdown} Solution

If A is zero and the record is included, B must be one, so the first probability is one. If A is one, both B values remain equally likely, so the second probability is one half.
:::

## Check your understanding

**Which adjustment can create a new noncausal association?**

- **A.** Conditioning on a blocked collider
- **B.** Recording a treatment definition
- **C.** Increasing the number of independent trials

:::{dropdown} Show the answer
**A. Conditioning on a blocked collider**

Conditioning on a collider can open its path. The resulting association can appear even when the original causes were independent.
:::

:::{caution} Scope and assumptions
A variable can play different roles on different paths. Check the full graph and the exact causal target.
:::

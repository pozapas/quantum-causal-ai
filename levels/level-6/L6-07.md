## Learn

A process matrix is an operator that assigns probabilities to local quantum instruments without first choosing one global causal order. Local laboratories still obey quantum mechanics. The global operator must satisfy positivity and normalization constraints for every permitted set of deterministic local operations.

In a compatible Choi convention, joint probabilities are a trace pairing of the process with local instrument Choi operators. This simple expression hides convention choices. Transposes can be absorbed into definitions. Import both the pairing and its constraints together, rather than mixing definitions across papers.

A positive operator with a convenient trace is not automatically a valid process matrix. The linear normalization conditions exclude operational loops that would give inconsistent probabilities. For a proposed example, test complete positivity and the full affine constraints of its named scenario.

:::{important} Key relation
:class: qcai-equation
p(a,b\|x,y) = Tr\[W (M\_a\|x tensor N\_b\|y)\] in the standard process-matrix pairing convention. Deterministic maps require Tr\[W(M tensor N)\] = 1 for every local CPTP M,N.
:::

:::{tip} Worked example
For laboratories with no outputs, a shared density operator rho\_AB is a valid process. Local operations are POVM effects. Summing the Born probabilities gives Tr\[rho\_AB(I tensor I)\] = 1. With nontrivial outputs, this state-only normalization argument is no longer sufficient.
:::

## Practice

:::{admonition} Exercise
:class: tip

A candidate W is positive and gives normalized probabilities for one pair of deterministic maps. Does this establish process validity? Name the missing requirement.
:::

:::{dropdown} Solution

No. Normalization must hold for every allowed pair of local deterministic maps. The scenario-specific linear constraints encode that universal requirement. One tested pair cannot establish it.
:::

## Check your understanding

**Which condition is required beyond positive semidefiniteness?**

- **A.** Normalization for all permitted local deterministic operations
- **B.** A large enough trace for one setting
- **C.** A nonzero off-diagonal entry

:::{dropdown} Show the answer
**A. Normalization for all permitted local deterministic operations**

A process must return a normalized probability distribution for any allowed deterministic local operations. Positivity by itself does not impose that universal normalization.
:::

:::{caution} Scope and assumptions
The trace pairing here follows the process-matrix convention. Do not combine it directly with an incompatible Choi transpose convention.
:::

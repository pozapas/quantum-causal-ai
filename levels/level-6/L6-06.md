## Learn

A Bell inequality bounds correlations in a specified local hidden-variable model. A causal inequality instead constrains correlations under a stated class of causal orders and operational assumptions. The two names do not refer to the same bound or the same experimental question.

A process can lack a decomposition into fixed causal orders without violating a particular causal inequality. An operator witness and an observed probability inequality use different information. A witness can rely on trusted apparatus details that are unavailable in a device-independent correlation test.

Before interpreting either test, identify its allowed settings, outputs, communication routes, and independence assumptions. Then state the null model and its numerical bound. A value outside a bound has meaning only for that model. Experimental uncertainty must be evaluated separately.

:::{important} Key relation
:class: qcai-equation
A causal-order mixture has the form p = q p\_(A before B) + (1-q) p\_(B before A), with 0&lt;=q&lt;=1, for the stated operational scenario.
:::

:::{tip} Worked example
A researcher observes CHSH S = 2.5 from spacelike local measurements. This challenges the relevant local hidden-variable class. It does not establish indefinite causal order. A different experiment and a different null-model bound would be needed for that claim.
:::

## Practice

:::{admonition} Exercise
:class: tip

An operator witness detects causal nonseparability under trusted instruments. Can this alone be called a device-independent causal-inequality violation? Explain.
:::

:::{dropdown} Solution

No. A trusted-instrument operator witness and a device-independent probability inequality impose different assumptions. The witness result alone does not establish that the observed distribution violates a causal inequality.
:::

## Check your understanding

**Which statement is valid?**

- **A.** Every Bell violation proves indefinite causal order
- **B.** Every nonseparable process violates every causal inequality
- **C.** The tests constrain different specified model classes

:::{dropdown} Show the answer
**C. The tests constrain different specified model classes**

Bell locality and definite causal order are distinct assumptions. A valid interpretation must state the relevant model class instead of substituting one test for another.
:::

:::{caution} Scope and assumptions
A causal inequality belongs to a defined operational scenario. Do not transfer its bound to another set of ports or communication rules.
:::

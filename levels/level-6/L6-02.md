## Learn

A Choi operator represents a linear map as an operator on input and output spaces. This representation makes channel constraints accessible through matrix tests. Several normalization and transpose conventions exist. State the convention before importing a formula from another paper.

Use the unnormalized maximally entangled vector sum\_i \|i&gt;\|i&gt;. Apply the identity map to its first half and the channel to its second half. A channel has a positive Choi operator. Trace preservation requires that tracing out the output gives the input identity.

The channel action then contains a transpose on the input density operator. Omitting that transpose changes predictions for complex states. In causal networks, the same issue appears when connecting operators. A correct diagram must also specify the algebra used to connect its ports.

:::{important} Key relation
:class: qcai-equation
J\_E = sum\_ij \|i&gt;&lt;j\| tensor E(\|i&gt;&lt;j\|); E(rho) = Tr\_in\[(rho^T tensor I)J\_E\]; Tr\_out J\_E = I\_in. T is transpose in the chosen input basis.
:::

:::{tip} Worked example
For the identity qubit channel, J equals \|Omega&gt;&lt;Omega\| with \|Omega&gt; = \|00&gt; + \|11&gt;. Its trace is two, not one. The output partial trace is I. Substitution into the recovery formula returns rho, including its complex off-diagonal entries.
:::

## Practice

:::{admonition} Exercise
:class: tip

A replacement channel outputs a fixed qubit state sigma for every input. Write its Choi operator and check trace preservation.
:::

:::{dropdown} Solution

Its Choi operator is I\_in tensor sigma. Tracing out the output gives I\_in times Tr(sigma), hence I\_in. The recovery formula gives Tr(rho) sigma, which equals sigma for a state.
:::

## Check your understanding

**What is the trace of a trace-preserving qubit Choi operator in this convention?**

- **A.** One half
- **B.** One
- **C.** Two

:::{dropdown} Show the answer
**C. Two**

The output partial trace is the two-dimensional input identity. Taking the remaining trace therefore gives two in this unnormalized convention.
:::

:::{caution} Scope and assumptions
Some authors normalize the Choi operator to trace one. Their formulas require matching dimension factors and possibly different transpose conventions.
:::

## Learn

Conditioning selects records that already occurred. An intervention changes the physical operation that generates later data. In a quantum laboratory, an intervention can replace an instrument, prepare a new state, or route an incoming system through a selected channel.

A replacement map discards the input and prepares a chosen state. It removes dependence of that output state on the incoming system. This operation can break an incoming correlation. Merely selecting one measurement outcome usually does not perform the same physical change.

Measurement can disturb a quantum system. Its causal role must include both the outcome and the state transformation. A classical do expression does not by itself specify that transformation. Write the laboratory operation, its available setting, and its retained outcome before calculating effects.

:::{important} Key relation
:class: qcai-equation
R\_sigma(tau) = Tr(tau) sigma. R\_sigma is a replacement channel. For a normalized input tau, its output is sigma regardless of tau.
:::

:::{tip} Worked example
Two qubits share \|Phi+&gt;. Conditioning on Z outcome 0 at A leaves B in \|0&gt;. If A instead discards its qubit and prepares \|0&gt; without selecting an outcome, B remains I/2. The preparation action does not select B records.
:::

## Practice

:::{admonition} Exercise
:class: tip

Repeat this comparison with conditioning on A outcome 1. Give B after conditioning and B after an unselected replacement at A.
:::

:::{dropdown} Solution

After conditioning on outcome 1, B is \|1&gt;. After an unselected local replacement, B is still I/2. The local action cannot change the remote unconditional marginal.
:::

## Check your understanding

**Which operation is an input-independent replacement?**

- **A.** Keeping only outcome 0
- **B.** Reading the input label
- **C.** Discarding the input and preparing sigma

:::{dropdown} Show the answer
**C. Discarding the input and preparing sigma**

A replacement map has the same normalized output for every input. Selecting measurement records is conditioning and generally gives a different joint procedure.
:::

:::{caution} Scope and assumptions
Allowed interventions are part of the model. A result can change when the experimenter lacks access to the required laboratory operation.
:::

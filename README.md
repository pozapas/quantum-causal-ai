# Quantum Causal AI — an open, interactive course

**Read it online: https://pozapas.github.io/quantum-causal-ai/**

A free Jupyter Book that teaches quantum causal AI from first principles — counting, chance and causal graphs through quantum information, quantum causal models, indefinite causal order and quantum machine learning. 80 lessons across 8 levels (grade school to postdoctoral), 11 interactive labs, and verified references, videos and podcasts.

## Run locally

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt "jupyter-book==2.1.7" nbclient jupyter-server pytest
python -m ipykernel install --user --name qcai
python -m pytest -q tests          # numerical engine
jupyter-book start                 # live preview (uses the saved outputs)
python scripts/execute_notebooks.py # re-run every notebook and save fresh outputs
python scripts/check.py --only C1,C2,C3,C4,C9   # content, references, media, tests, style
```

## Layout

| Path | Contents |
|---|---|
| `levels/` | 80 lesson pages generated by `scripts/convert.py` from `_data/levels/*.json` |
| `labs/` | 11 executable lab notebooks |
| `qcai/` | the tested teaching engine (`science.py`) and the Plotly helper (`viz.py`) |
| `_data/` | verified references, media and link records |
